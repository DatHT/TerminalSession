Two ways to use it — pick either

Same engine underneath, so they behave identically.

Menu-bar app ⌥Space

A native macOS app: a >_ menu-bar icon and a floating search panel.

  • Global hotkey — no Accessibility permission needed
  • Type to filter, ↑↓ to move, ↵ to focus, Esc to close
  • Multi-terminal folders expand with → to pick

Shell command tm

A bash + zsh function for people who live in the terminal.

  • tm — fuzzy-pick a folder → focus it
  • tm ~/dev/foo — reuse or open there
  • tm ls · tm doctor

Install in a minute

Needs macOS 13+, Node.js, and the Xcode command-line tools to build the app.

# clone & build the menu-bar app git clone https://github.com/DatHT/TerminalSession.git cd TerminalSession bash app/build.sh open app/build # drag "Terminal Sessions.app" into /Applications # then press ⌥Space anywhere ✦

Prefer the terminal? . "$PWD/shell/tm.sh" in your ~/.zshrc and type tm.

How it works

No daemon, nothing to sync — it just reads live state.

01

Enumerate

AppleScript lists every open Terminal.app & iTerm2 tab and its TTY.

02

Resolve

Each TTY → its foreground process → its working directory via ps + lsof.

03

Group

Tabs grouped by folder, each labelled by what's running in it.

04

Jump

Focuses the exact tab — or opens a new window cd'd into the folder.
